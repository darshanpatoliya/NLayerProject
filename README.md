# Inventory Management — N-Layer Architecture

A C# inventory management application demonstrating separation of concerns through a layered architecture.

## Overview

The project organizes application responsibilities into distinct layers to improve maintainability, testability, and separation of concerns.

## Technology

- C#
- .NET / Windows Forms
- N-Layer Architecture
- Database-driven application design

## Architecture Focus

The implementation demonstrates how presentation, business logic, and data-access responsibilities can be separated rather than placing application logic in a single layer.

## Purpose

Built to practice enterprise-oriented application structure and understand how layered architecture supports maintainable software.
